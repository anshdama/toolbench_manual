FAQ

Answers to the most common questions about using the Tool Bench system. If your question isn’t answered here, refer to the relevant tool manual or the Safety page.

Question 01

Why is my voltage reading showing a large error value?

A large ± error on the Voltmeter usually means the readings are inconsistent between samples. The most common causes are an unstable voltage source, a loose connection at the banana plug terminals, or electrical noise in the environment. Start by checking that both the positive and ground connections are firmly seated. If the source itself is unstable (for example, a battery under load) the error will naturally be higher. For the most consistent results, use a regulated power supply and keep leads short.

Question 02

The Ohmmeter is showing R: None — what does that mean?

R: None means the system could not detect a valid resistance on the input terminals. This happens when no component is connected, when the component’s resistance is outside the measurable range of approximately 500Ω to 10kΩ, or when the connection is too loose to register. Check that the resistor legs are properly inserted — one leg into any pin from G through J - 26 and the other into ground. If the resistor is within range and the connection looks good, try a different component to rule out a faulty part.

Question 03

Does the Function Generator output turn off automatically when I leave the menu?

Yes. Any time you navigate away from the Output page. Whether by selecting Back or Main from inside the Output page — the output is turned off automatically. You do not need to manually disable it first. This is a safety feature to prevent a signal from staying active while you are working elsewhere in the menus. If you need the output to stay on, you must remain on the Output screen.

Question 04

What is the difference between the DC Reference measured value (M) and the set value (S)?

The set value (S) is the voltage you chose from the list — the target the system is trying to produce. The measured value (M) is what the built-in Voltmeter actually reads at the output terminals in real time. A small difference between the two is completely normal and is caused by component tolerances in the hardware circuit. The measured value refreshes approximately once per second, so give it a moment to settle right after enabling the output before drawing conclusions about accuracy.

Question 05

Can I connect a voltage source greater than ±5V to the Voltmeter input?

No. The Voltmeter is rated for a maximum of ±5V DC. Connecting a source outside this range can produce incorrect readings and may damage the internal measurement hardware. Please refrain from doing so under any circumstances.
