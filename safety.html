Safety

Read this page before connecting anything to the Tool Bench system. The hardware is designed to be safe when used correctly, but exceeding its rated limits or connecting inappropriate components can cause incorrect readings, damage to the system, or injury. Following the guidelines below will keep both you and the equipment safe.

Warning: Always review the relevant tool manual before use. Each tool has its own input limits and connection requirements.
Voltage Limits

Stay Within the Rated Voltage Range

The Voltmeter and DC Reference inputs are rated for a maximum of ±5V DC. Never connect a voltage source that exceeds this range to any terminal on the system. Overvoltage can permanently damage the internal measurement hardware. If you are unsure what voltage your source is producing, measure it with an external multimeter before connecting it to the Tool Bench. The Function Generator output also operates within a ±10V peak range and should only be connected to high-impedance loads.

Connections

Observe Correct Polarity and Terminal Assignment

Always connect the positive wire to the red terminal and the ground wire to the black terminal when using the Voltmeter with an external source. Reversed polarity will not damage the system but will produce an incorrect reading. For the DC Reference and Function Generator outputs, connect your device’s signal input to the DC Out terminal and its ground to the Ground terminal. Never swap these as a floating or inverted signal on your oscilloscope or load is the typical result of incorrect connections.

Ohmmeter

Only Connect Passive Resistors to the Ohmmeter

The Ohmmeter is designed to measure passive resistors only. Do not connect powered components, voltage sources, capacitors, inductors, or anything that can source current into the Ohmmeter terminals. Doing so can damage the internal circuitry. Additionally, only components with a resistance between approximately 500Ω and 10kΩ will produce valid readings — values outside this range will display R: None and should not be forced.

Function Generator

Drive High-Impedance Loads Only

The Function Generator output is not designed to source significant current. Only connect it to high-impedance loads such as an oscilloscope input or a high-impedance circuit input. Connecting low-impedance loads (such as speakers, motors, or low-value resistors) can overload the output stage and damage the hardware. If you are using the output to drive a circuit, verify that the input impedance of your load is appropriate before enabling the signal.

General

General Handling and Use

Do not operate the Tool Bench on conductive surfaces or near liquids. Ensure all connections are secure before enabling any output — loose wires can cause intermittent shorts or unexpected readings. Turn off any active output (Voltmeter, DC Reference, or Function Generator) before disconnecting leads. When finished, navigate back to the main menu so no output remains active unintentionally. If the system displays unexpected values or behaves abnormally, disconnect all external connections and power cycle the device before continuing.

Note: If you are a complete beginner, work through each tool manual step by step before attempting to connect external components. The manuals include images of the correct setup at every stage. There is also a demonstration video link avaliable at the bottom of each manual page.
